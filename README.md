# Ronal's Curiosity

An open expedition through questions, ideas, and challenges. Two environments: Space and Jungle.

This directory is ready for GitHub Pages. All assets are included and use relative paths, including for a project site hosted below a repository name. It needs no local server, installation, or build step.

## Publishing

Recommended repository: nel1995h-lab/ronals-curiosity (new, separate repository).
In repository Settings → Pages, choose Deploy from a branch, main, / (root).
Publishing must be approved by the owner. The URL is not live until deployment succeeds.
Changes committed to the publishing branch will update the website; editing the local preview alone will not publish changes.

## Visitors' notes

Notes remain in browser memory during a visit. Visitors can copy or download them. No notes are collected by this site. The legacy challenge form opens separately at https://nelformpage.carrd.co and is not automatically populated.

The local live-preview server and development-only tools are excluded.
